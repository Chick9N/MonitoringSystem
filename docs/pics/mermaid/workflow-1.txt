flowchart TD
    A([开始]) --> B[用户选择数据源和协议]
    B --> C[填写名称、通信参数和阈值]
    C --> D{完整参数/阈值校验通过?}
    D -- 否 --> E[显示具体字段错误]
    E --> C
    D -- 是 --> F[构建设备配置]
    F --> G{配置写入数据库成功?}
    G -- 否 --> H[回滚未完成写入并显示存储错误]
    H --> Q([结束])
    G -- 是 --> I[注册设备并初始化通信资源]
    I --> J{设备注册成功?}
    J -- 否 --> R[删除已写入配置并报告初始化失败]
    R --> Q
    J -- 是 --> K[通过设备新增结果更新主界面]
    K --> L{用户是否启用采集?}
    L -- 是 --> M[建立连接并纳入轮询]
    L -- 否 --> N[保持待启用状态]
    M --> P[显示设备和通信状态]
    N --> P
    P --> Q
